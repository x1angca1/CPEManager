# P1 功能扩展实施计划（重启/限额/信号曲线/固件检查 + CI 测试）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 CPEManager 中加入一键重启、每日流量限额+清零、信号历史曲线、固件更新检查，并让 CI 运行单元测试。

**Architecture:** 沿用现有两层：CpeProtocol.cpp 增加协议函数（XML 请求 + Parse* 解析），main.cpp 的 HandleMessage 增加消息分支，新 UI 面板放独立 JS 文件注入。信号历史存 EXE 同目录 JSON。

**Tech Stack:** C++17 / WinHTTP / WebView2（现有）；UI 为原生 JS + Canvas（不引库）；构建走 GitHub Actions（本机无 MSVC）。

**Spec:** `docs/superpowers/specs/2026-09-25-feature-expansion-design.md`

## Global Constraints

- 界面文案全部中文；不引入任何第三方库。
- 所有协议函数沿用现有 `Request()` + `<request>...</request>` XML 模式，错误出参 `std::wstring& error`。
- 本机无 MSVC：**"运行测试" = 提交推送 + 等 Actions 完成**（约 2-3 分钟，`gh run watch` 或 `gh api .../runs` 查询）。每个任务独立提交推送。
- POST 体字段名按同名 GET 字段回传（HiLink 惯例）；设备验收步骤校准，服务器拒绝时以错误码反馈调整。
- 提交信息末尾加 `Co-Authored-By: Claude Code <noreply@anthropic.com>`。
- 设备实测基线（2026-09-25 真机探测）：daily-data-limit、online-update/status 均可用；USSD/天线扫描/eSIM/最佳位置在本机不支持（P2/P3 不做）。

## Review Focus

1. **daily-data-limit XML 变体**：字段大小写混用（`DayDataLimit` vs `dailytrafficmaxlimit`），解析必须大小写敏感地按实测 fixture 取值 — Task 2 测试固定真实 fixture。
2. **限额单位歧义**：`DayDataLimit=0MB` 是字符串、"0" 是未设置；UI 必须区分"未设置"与"0 MB"，否则用户设 0 会被当禁用 — Task 5 处理。
3. **signal-history.json 损坏/超大**：手改坏、断电半写、超过 7 天 — Task 8 测试覆盖：坏文件改名备份从空开始；超期裁剪。
4. **重启后通信**：重启期间所有请求超时/报错，UI 不能崩或无限报错弹窗 — Task 6 重启后轮询重连。
5. **并发写文件**：信号轮询线程 flush 与退出时 flush 撞车 — Task 8 退出时同线程串行写（沿用 PostMessage WM_APP+1 模式排队到 UI 线程）。

```cpp
bool CpeProtocol::ParseDailyLimit(const std::wstring& response, CpeDailyLimitData& data) {
    if (response.find(L"<response") == std::wstring::npos) return false;
    data = {};
    data.dayDataLimit = XmlValue(response, L"DayDataLimit");
    data.dailytrafficmaxlimit = XmlValue(response, L"dailytrafficmaxlimit");
    data.dailyturnoffdataenable = XmlValue(response, L"dailyturnoffdataenable");
    data.dailyturnoffdataswitch = XmlValue(response, L"dailyturnoffdataswitch");
    return !data.dayDataLimit.empty() || !data.dailytrafficmaxlimit.empty();
}

bool CpeProtocol::FetchDailyDataLimit(CpeDailyLimitData& data, std::wstring& error) {
    const Response response = Request(L"GET", L"/api/monitoring/daily-data-limit");
    if (response.networkError != ERROR_SUCCESS) { error = L"每日限额请求未送达（网络错误 " + std::to_wstring(response.networkError) + L"）。"; return false; }
    if (response.status != 200) { error = L"每日限额 HTTP " + std::to_wstring(response.status); return false; }
    if (!ParseDailyLimit(response.body, data)) { error = L"每日限额响应解析失败。"; return false; }
    return true;
}
```

```cpp
std::wstring CpeProtocol::BuildDailyLimitRequest(const CpeDailyLimitData& data) {
    return L"<?xml version=\"1.0\" encoding=\"UTF-8\"?><request><dailytrafficmaxlimit>" + EscapeXml(data.dailytrafficmaxlimit)
         + L"</dailytrafficmaxlimit><dailyturnoffdataenable>" + EscapeXml(data.dailyturnoffdataenable)
         + L"</dailyturnoffdataenable><dailyturnoffdataswitch>" + EscapeXml(data.dailyturnoffdataswitch)
         + L"</dailyturnoffdataswitch></request>";
}

bool CpeProtocol::SetDailyDataLimit(const CpeDailyLimitData& data, std::wstring& error) {
    const Response response = Request(L"POST", L"/api/monitoring/daily-data-limit", BuildDailyLimitRequest(data), NextVerificationToken());
    if (response.networkError != ERROR_SUCCESS) { error = L"保存每日限额未送达（网络错误 " + std::to_wstring(response.networkError) + L"）。"; return false; }
    const std::wstring code = XmlValue(response.body, L"code");
    if (response.status != 200 || !code.empty()) { error = L"保存每日限额失败" + (code.empty() ? L"。" : L"（错误码 " + code + L"）。"); return false; }
    return true;
}

bool CpeProtocol::ClearTrafficStatistics(std::wstring& error) {
    const Response response = Request(L"POST", L"/api/monitoring/clear-traffic", L"<?xml version=\"1.0\" encoding=\"UTF-8\"?><request></request>", NextVerificationToken());
    if (response.networkError != ERROR_SUCCESS) { error = L"清零请求未送达（网络错误 " + std::to_wstring(response.networkError) + L"）。"; return false; }
    const std::wstring code = XmlValue(response.body, L"code");
    if (response.status != 200 || !code.empty()) { error = L"清零失败" + (code.empty() ? L"。" : L"（错误码 " + code + L"）。"); return false; }
    return true;
}

bool CpeProtocol::RebootDevice(std::wstring& error) {
    const Response response = Request(L"POST", L"/api/device/control", L"<?xml version=\"1.0\" encoding=\"UTF-8\"?><request><reboot>1</reboot></request>", NextVerificationToken());
    if (response.networkError != ERROR_SUCCESS) { error = L"重启请求未送达（网络错误 " + std::to_wstring(response.networkError) + L"）。"; return false; }
    const std::wstring code = XmlValue(response.body, L"code");
    if (response.status != 200 || !code.empty()) { error = L"重启失败" + (code.empty() ? L"。" : L"（错误码 " + code + L"）。"); return false; }
    return true;
}

bool CpeProtocol::ParseUpdateStatus(const std::wstring& response, CpeUpdateStatus& status) {
    if (response.find(L"<response") == std::wstring::npos) return false;
    status = {};
    status.currentComponentStatus = XmlValue(response, L"CurrentComponentStatus");
    status.forcedUpdate = XmlValue(response, L"forcedupdate");
    return !status.currentComponentStatus.empty();
}

bool CpeProtocol::FetchUpdateStatus(CpeUpdateStatus& status, std::wstring& error) {
    const Response response = Request(L"GET", L"/api/online-update/status");
    if (response.networkError != ERROR_SUCCESS) { error = L"固件状态请求未送达（网络错误 " + std::to_wstring(response.networkError) + L"）。"; return false; }
    if (response.status != 200 || !ParseUpdateStatus(response.body, status)) { error = L"固件状态获取失败。"; return false; }
    return true;
}

bool CpeProtocol::CheckNewVersion(std::wstring& error) {
    const Response response = Request(L"POST", L"/api/online-update/check-new-version", L"<?xml version=\"1.0\" encoding=\"UTF-8\"?><request></request>", NextVerificationToken());
    if (response.networkError != ERROR_SUCCESS) { error = L"版本检查请求未送达（网络错误 " + std::to_wstring(response.networkError) + L"）。"; return false; }
    const std::wstring code = XmlValue(response.body, L"code");
    if (response.status != 200 || !code.empty()) { error = L"版本检查失败" + (code.empty() ? L"。" : L"（错误码 " + code + L"）。"); return false; }
    return true;
}
```

```cpp
#pragma once
#include <string>

inline void AppendSignalSample(std::wstring& log, const std::wstring& unixTime, const std::wstring& rsrp, const std::wstring& sinr) {
    log += unixTime + L"," + rsrp + L"," + sinr + L"\n";
}

inline bool TrimSignalHistory(std::wstring& log, long long nowUnix, long long keepSeconds) {
    const long long cutoff = nowUnix - keepSeconds;
    std::wstring kept; bool changed = false;
    size_t begin = 0;
    while (begin < log.size()) {
        const size_t end = log.find(L'\n', begin);
        const std::wstring line = log.substr(begin, (end == std::wstring::npos ? log.size() : end) - begin);
        const size_t comma1 = line.find(L',');
        if (comma1 != std::wstring::npos) {
            try {
                if (std::stoll(line.substr(0, comma1)) < cutoff) changed = true;
                else { if (!kept.empty()) kept += L"\n"; kept += line; }
            } catch (...) { changed = true; }   // 坏时间戳行直接丢弃
        } else changed = true;                  // 坏行丢弃
        if (end == std::wstring::npos) break;
        begin = end + 1;
    }
    if (changed) { log = kept.empty() ? kept : kept + L"\n"; }
    return changed;
}
```
